Für Institutionen

Bauen Sie Ihre Vorlage. Sehen Sie sofort, wie sie in Vivodepot aussieht.

Kein Konto, keine Installation. Alles läuft in Ihrem Browser, und nichts wird gesendet, bevor Sie es selbst versenden. Probieren Sie so lange, wie Sie möchten.

Womit möchten Sie anfangen?

So läuft es ab

  1. 1
    Bauen

    Felder wählen, anordnen, Vorschau ansehen. Probieren Sie, so lange Sie möchten; es wird noch nichts von Ihnen verlangt.

  2. 2
    Angaben und Schlüssel

    Erst wenn Sie fertig sind: wer Sie sind und ein digitaler Schlüssel, der die Vorlage Ihnen zuordnet.

  3. 3
    Absenden

    Sie erhalten eine Datei. Schicken Sie sie per E-Mail an Vivodepot; die Prüfung dauert einige Werktage.

Weitere Möglichkeiten

Das sind signierte Datenbündel, keine Formular-Vorlagen. Sie nutzen dieselben Angaben und denselben Schlüssel wie eine Vorlage; haben Sie diese noch nicht eingegeben, fragt das Fenster „Fertigstellen“ danach.

Oder: eine Anfrage stellen

Eine Anfrage beschreibt, welche Angaben Sie von einer Person brauchen — und wozu. Sie enthält keine Personendaten: Sie nennen nur die Felder, nicht deren Inhalt. Die Person sieht Ihren Zweck und Ihre Grundlage, bevor sie antwortet.

Empfangs-Schlüsselpaar

Für das Schlüsselpaar-Verfahren brauchen Sie ein zweites Paar — das aus „Fertigstellen“ signiert nur, es kann nichts entschlüsseln. Der öffentliche Teil reist in der Anfrage; mit dem privaten öffnen Sie später jede Antwort. Er wird nirgends gespeichert.

Welche Angaben brauchen Sie?

Aufgenommen (0)

Oder: das Angebot einer Person beantworten

Bevor eine Person Ihnen Daten gibt, kann sie eine Bedingung dafür festlegen. Sie bekommen dann ein Angebot als Datei oder QR-Code. Nehmen Sie eine der angebotenen Bedingungen an oder lehnen Sie ab. Die Antwort wird mit Ihrem Schlüssel signiert; behalten Sie eine Kopie. Was eine Bedingung besagt, lesen Sie bei ihrer Quelle.

Oder: eine fehlende Kennung vorschlagen

Fehlt im Feldkatalog eine Angabe, die Ihre Vorlage braucht? Schlagen Sie sie vor — die Vivodepot GmbH entscheidet binnen höchstens fünf Arbeitstagen. Eine Kennung wird nie erfunden, nur vorgeschlagen und freigegeben.

Vorgemerkt (0)

Oder: eine Institutions-Art ergänzen

Vivodepot kennt zwölf eingebaute Institutions-Arten (Krankenkasse, Pflegedienst, Standesamt …). Fehlt eine — etwa für ein anderes Land — können Sie sie hier als eigenes Modul ergänzen. Es enthält nur Kennungen und Beschriftungen, keine Personendaten.

Institutions-Arten

Oder: einen neuen Lebensbereich ergänzen

Vivodepot ordnet Angaben in Lebensbereiche (Gesundheit, Finanzen, Vorsorge …). Fehlt ein ganzer Bereich für Ihren Fall, können Sie ihn hier als eigenes Modul ergänzen — mit eigenem Namen und Symbol. Er enthält selbst noch keine Felder, nur den Rahmen, in den spätere Vorlagen andocken.

Bereiche

Oder: einen Assistenten (Wizard) ergänzen

Ein Assistent führt Schritt für Schritt durch eine Reihe von Fragen und trägt die Antworten in ein Ziel ein (eine Situation oder einen Bereich). Dieses Werkzeug baut, prüft und signiert das Modul — die Fragen selbst tragen Sie als fertigen JSON-Text ein, dieses Werkzeug entwirft sie nicht.

Assistenten

Oder: ein Logikmodul (Auszug/Auswertung) ergänzen

Ein Logikmodul liest Angaben aus einem Bereich und stellt sie als eigenen Auszug zusammen (zum Beispiel eine Frage-Antwort-Übersicht). Dieses Werkzeug baut, prüft und signiert das Modul — Datenschema, Abschnitte und Dokument-Ausgabe tragen Sie als fertigen JSON-Text ein, dieses Werkzeug entwirft sie nicht.

Oder: ein Sprachmodul prüfen und ausgeben

Ein Sprachmodul bringt Vivodepot in eine Sprache: jeder Text des Produkts unter seiner Kennung. Dieses Werkzeug schreibt es nicht. Sie stellen die Datei (JSON, rund 3 850 Texte) mit Ihrem eigenen Übersetzungswerkzeug her und laden sie hier; das Werkzeug prüft sie und gibt sie aus — signiert, wenn Ihr Schlüssel geladen ist. Eine Partnerin kann Vivodepot mit diesem Werkzeug allein also nicht übersetzen.

Was dieses Werkzeug NICHT prüft: ob die Kennungen Ihrer Texte dem Produkt bekannt sind. Das prüft erst der Einlass des Produkts beim Einlassen — er verwirft unbekannte Kennungen einzeln, lehnt ein Modul ab, von dem keine einzige Kennung übernommen wird, und meldet, wenn ein Teil verloren geht. Ebenso erst dort geprüft: ob ein Text ein Zusicherungssatz ist, die Regeln des Moduls und die Ausnahmen für Absatz-HTML.

Oder: einen Rechtsraum ergänzen

Vivodepot deckt Deutschland eingebaut ab. Für ein bekanntes Rechtsinstrument (z. B. eine Vorsorgevollmacht) in einem anderen Rechtsraum können Sie hier den dortigen Wortlaut und die dortigen Formvorschriften ergänzen. Vivodepot prüft nur die Form Ihrer Angaben, nicht deren rechtlichen Inhalt — das bleibt Ihre Verantwortung als Herausgeber.

Ein Format-Modul beschreibt, wie eine fremde Datei gelesen oder geschrieben wird — z. B. ein Export aus Ihrem eigenen System, den eine Bürgerin nach Vivodepot holen können soll. Sie schreiben keinen Code: Sie wählen einen der eingebauten Leser und benennen, welche Angaben in welche Vivodepot-Felder gehören.

Hilfe

Was ist ein Template?

Ein Template ist die Liste der Datenfelder, die Bürgerinnen und Bürger später bei Ihnen einreichen können, zum Beispiel ein Aufnahmebogen oder ein Anamnese-Formular.

Was bewirkt die Zertifizierung?

Vivodepot bestätigt offiziell, dass dieses Template von Ihnen kommt. So können sich alle Beteiligten darauf verlassen, dass die Felder echt und von Ihrer Institution autorisiert sind.

Wie lange dauert das?

Das Bauen dauert, so lange Sie möchten; eine einfache Vorlage ist in Minuten fertig. Die Prüfung durch Vivodepot dauert anschließend einige Werktage.

Was geschieht mit meinen Daten?

Nichts verlässt Ihren Browser, bis Sie die fertige Datei selbst versenden. Es gibt keinen automatischen Versand und keine Speicherung auf einem Server.

Glossar

Bereich
Eine der dreizehn Vivodepot-Kategorien (z. B. Gesundheit, Finanzen, Vorsorge).
Code-System
Ein standardisierter Katalog von Codes (z. B. LOINC für Messwerte, ICD-10 für Diagnosen).
Trust-Authority
Die Stelle bei Vivodepot, die Templates zertifiziert. Sie bestätigt, von wem ein Template kommt, nicht ob sein Inhalt richtig ist.
Zertifikat
Bestätigt, von wem ein Template kommt. Eine Aussage darüber, ob der Inhalt richtig ist, ist es nicht.
FHIR
Internationaler Standard für den Austausch von Gesundheitsdaten.

Häufige Fragen

Was kostet das?
Die Konditionen für die Zertifizierung teilt Ihnen Vivodepot direkt mit.
Was passiert bei Ablehnung?
Sie erhalten eine Rückmeldung mit Hinweisen und können ein überarbeitetes Paket erneut einreichen.
Wie aktualisiere ich später mein Template?
Mit Ihrem aufbewahrten privaten Schlüssel erstellen Sie ein aktualisiertes Paket und reichen es erneut ein.
